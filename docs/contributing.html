Contributing

Help build A#

Branch off, never commit to main — the maintainer reviews and merges every PR. Full workflow in the guide below.

Official Brand Kit

Electric Green on True Black. Satoshi for headings and UI, JetBrains Mono for code. Full usage rules and clearspace requirements in the Branding guide.

Full Branding Guide → Design System

Before You Start

A# has a defined direction — read VISION.md and ARCHITECTURE.md before proposing a feature. For anything beyond a small fix, open an issue first.

Local Setup

terminal
$ git clone https://github.com/aymanissa-dev/asharp.git $ cd asharp $ npm install

Submitting Changes

Create a branch → make your change → confirm the affected package compiles cleanly (npx tsc --noEmit) → open a pull request. Only the maintainer merges into main.
