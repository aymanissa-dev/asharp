Getting Started

Get up and running with A#

The current CLI workflow — everything here is real, working code.

terminal
$ npx asharp create my-app ✔ Created project: my-app Next steps: cd my-app npm install npm run build && npm start

What create gives you

A real, minimal TypeScript project — package.json, tsconfig.json (strict mode, ESM), and a runnable src/index.ts. No framework code inside it yet; A#'s component model and rendering live in @asharp/core, which the CLI is wired to but doesn't yet inject into generated projects.

Feature status

An honest snapshot — built vs. still ahead. Full detail in the Roadmap.

Built

CLI scaffolding

asharp create [name] generates a real, runnable TypeScript project — interactive prompt or positional argument.

Built

Application lifecycle

createApplication() in @asharp/core — A#'s entry point.

Built

Typed component model

Component<TProps> — typed, composable functions from props to output.

Built

A#'s own JSX runtime

Real .tsx syntax compiles through A#'s transform, not React's.

Built

DOM rendering

Components render real, visible content in the browser — proven end-to-end.

Wired

asharp dev / build / preview

All call @asharp/core's lifecycle with purpose-appropriate messaging. Not yet a real dev server, bundler, or preview server.

Ahead

State & events

Local component state and event handling (clicks, input) — not yet built.

Routing & styling

Integrated routing and CSS/Tailwind support — not yet built.

Ahead

Backend/API layer
