Components

        
HTML, CSS, and JavaScript stay separate — and connected.

        

          Folder name equals component identity. A# automatically associates the
          matching HTML, CSS, and JavaScript files.
        

        
components/
└── navbar/
    ├── navbar.html
    ├── navbar.css
    └── navbar.js

        
<a-navbar></a-navbar>

        
export default {
  mount({ root, props }) {
    const button = root.querySelector("button");
    button.addEventListener("click", () => {
      console.log("clicked");
    });
  },
  destroy() {
    // cleanup
  }
};

      

    


    

      

        
Routing

        
Filesystem conventions become application structure.

        

          
            

              File
              URL
            

          
          
            

              src/app/page.html
              /
            

            

              src/app/about/page.html
              /about
            

            

              src/app/contact/page.html
              /contact
            

          
        

        

          Navigation uses ordinary HTML links. A# intercepts internal navigation
          via the History API while retaining back/forward browser behavior.

Framework Direction

        

          A batteries-included application framework, not merely a UI library.
        

        

          

            
Structured & Enterprise-Ready

            

              Architecture, dependency injection, services, forms, deep routing,
              CLI/tooling, enterprise maintainability.
            

          

          

            
Modern Web Capabilities

            

              File routing, layouts, SSR/SSG, SEO, server features, data
              loading, production DX.
            

          

          

            
A# Contribution

            

              HTML-first authoring, CSS-first styling, JavaScript-first
              behavior, convention over configuration, native web APIs.
            

          

        

        

          A# borrows principles, not APIs. The framework needs its own coherent
          architecture.
